# admincom

PeeringDB Admin Committee (AC) operations repo — tracks AC work: admin onboarding/deboarding
requests, support/data-fix tickets, and DeskPro snippet/macro maintenance.

## Issues

- Onboarding a new admin? Use the **Onboard Admin** issue template.
- Removing one? Use the **Remove Admin** issue template.
- Other AC work (bugs, support requests) can be filed as a plain issue.

## Userscripts

Tampermonkey/Greasemonkey tooling for PeeringDB CP/FP and DeskPro admin workflows lives in
[`user.js/`](user.js/) — see [`user.js/README.md`](user.js/README.md) for installation and usage.
